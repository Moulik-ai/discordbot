# 🤖 Discord Multi-Utility Bot

A feature-rich Discord bot built using **C#** that combines moderation tools, music playback, weather information, API integrations, utility commands, and server management features into a single package.

Designed to make Discord servers more interactive, organized, and efficient.

---

## ✨ Features

### 🎵 Music Commands
- Play music from supported sources
- Pause and resume tracks
- Skip songs
- Stop playback
- Queue management

### 🌦️ Weather Information
- Get real-time weather updates
- Check temperature and conditions for any city
- Fast and accurate weather retrieval through APIs

### 🛠️ Moderation Tools
- Kick members
- Ban members
- Mute/Unmute users
- Clear messages
- Manage server activity efficiently

### 🔗 API Integrations
- Fetch data from external APIs
- Utility and information commands
- Dynamic response generation

### ⚡ Utility Commands
- Ping command
- Server information
- User information
- Help command
- General productivity features

## 🚀 Getting Started

### Prerequisites

- .NET SDK
- Discord Developer Account
- Discord Bot Token
- API Keys (if required)

### Installation

1. Clone the repository

```bash
git clone https://github.com/Moulik-ai/discordbot.git
```

2. Navigate to the project directory

```bash
cd discordbot
```

3. Configure your bot token and API keys

```json
{
  "Token": "YOUR_DISCORD_BOT_TOKEN",
  "WeatherApiKey": "YOUR_API_KEY"
}
```

4. Build the project

```bash
dotnet build
```

5. Run the bot

```bash
dotnet run
```
